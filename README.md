# EthioHealth Access

24/7 platform for health-facility access, ambulance routing, and
travel-time analysis across Ethiopia.

Stack: Streamlit (EN/Amharic) | OSRM | HDX + OSM + WorldPop + ALOS AW3D30 |
PostGIS | Google Earth Engine.
